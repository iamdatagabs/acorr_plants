# Análise de Correspondência — Ocorrência de Plantas

Projeto exploratório de Análise de Correspondência (AC) aplicado a uma base de ocorrência de plantas em uma região da Suécia.

## Objetivo
Explorar associações entre categorias de uma tabela de contingência e representar padrões de proximidade em um espaço de baixa dimensão.

## Interpretação
A distância entre pontos no mapa fatorial deve ser interpretada conforme a massa, a contribuição e a qualidade de representação das categorias. A visualização não demonstra causalidade nem substitui a análise da tabela original.

Consulte os scripts e dados do repositório para identificar as etapas efetivamente implementadas.
